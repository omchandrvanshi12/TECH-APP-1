# Future Shadow Classes

A classroom web app for teachers and students to:

- log in with email/phone and role-based access
- create live or upcoming classes
- generate automatic Jitsi meeting links
- upload PDF/image resources and class notes
- view uploaded materials from the student portal

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm start`

## Notes

- Frontend: React + Vite
- Backend: Express + SQLite
- Static uploads are served from the `uploads` folder
